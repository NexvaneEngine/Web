What is Nexvane?

Nexvane is an open-source, cross-platform game engine written in C++. It renders through its own pipeline, so your project behaves the same on every platform. Script your gameplay in native C++ or Neptune, Nexvane's own DSL, and deploy to:

  • Windows (10, 11)
  • macOS (Apple Silicon and Intel)
  • Linux (X11 and Wayland)
  • iOS and Android

For exact version and architecture details, see System Requirements.

Key capabilities

Capability Description
Cross-platform rendering Nexvane's own rendering engine produces consistent output on every platform. No native control wrappers, no platform-specific quirks.
Native and Neptune scripting Write gameplay in native C++ for full control, or Neptune for faster iteration.
Entity Component System Nexvane's ECS keeps gameplay logic and data separate for predictable performance at scale.
