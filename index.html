Overview

Nexvane Editor

The Nexvane editor provides a clean interface to manipulate, create and explore assets, handle scene hierarchies and manipulate the scene on real time as you run your project in the editor.

Neptune Programming Language

Although Nexvane provides native C++ scripting, We also provide a DSL called Neptune designed to integrate with Nexvane's workflow and features and allows interoperability with other supported languages.

Statically Typed Assets

Assets are directly reflected into the code to prevent runtime and mismatch errors. Missing or invalid asset references are caught at compile time.

Networking

Networking was integrated from day one. Build single-player or multi-player games with an Authoritative Server architecture and Network Entity Ownership.

Package System

Extend your projects and customize your workflow installing official, community our your own Nexvane packages, including assets, scripts and editor modules.

Visual Scripting

Supports block-based visual scripting language that integrates with C++ and Neptune.
