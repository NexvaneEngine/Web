User Manual

Installation

Download the Nexvane Editor for your platform from the Download menu and run the installer. Windows and Linux builds are both x64 and share the same project format.

Quick Start

Create a new project from the launcher, pick a template, and open it in the editor. The editor watches your project folder and hot-reloads assets and Neptune scripts as you save them.

Interface Overview

The editor is split into a scene view, an inspector, and an asset browser. Panels can be rearranged and docked to match your workflow.

Scene Hierarchy

Scenes are trees of entities, mirroring this sidebar's own node/leaf structure - parent entities can be expanded to reveal their children, and any entity can be selected directly.

Importing Assets

Drag files into the asset browser to import them. Nexvane generates a statically typed reference for every asset so missing or renamed files are caught at compile time rather than at runtime.

Static Typing

Every asset reference used in C++ or Neptune code is checked against the project's asset manifest during the build step.

Networking

Nexvane ships with an authoritative-server networking model and network entity ownership built in, so multiplayer projects don't need a third-party plugin.

Installing Packages

Packages can be installed from the official registry, a community source, or a local path, and may contain assets, scripts, or editor modules.

Publishing a Package

Run the package export command from the CLI to bundle your assets and scripts into a distributable package manifest.
