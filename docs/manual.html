User Manual

Installation

Nexvane is available for Windows and Linux with a x64 architecture. Download the installer from the Downloads page, or build it from source on any supported platform.

Quick Start

Create a new project from the launcher, pick a template, and the editor opens straight into the scene view. From there you can drag assets in, wire up a scene hierarchy, and hit play to run your project directly inside the editor.

System Requirements

A x64 CPU, a GPU with modern graphics API support, and at least 8GB of RAM are recommended for a comfortable editing experience on larger projects.

Scene Hierarchy

The editor's scene panel mirrors your project's object hierarchy in real time, including changes made while the project is running — reparent, rename, or duplicate objects without stopping playback.

Asset Pipeline

Assets are statically reflected into code, so a renamed or missing asset reference is caught at compile time instead of failing silently at runtime.

C++ Scripting

Nexvane exposes its engine APIs natively to C++, giving you full control over performance-critical systems without a scripting-layer overhead.

Neptune: Syntax Basics

Neptune is Nexvane's own DSL, designed to read close to C++ while trimming the boilerplate that gameplay scripting doesn't need day to day.

Neptune: Interop with C++

Neptune scripts can call into C++ systems and vice versa, so you can prototype gameplay quickly in Neptune and drop down to C++ for the parts that need it.

Authoritative Server

Multiplayer projects run on an authoritative-server model by default, so gameplay-critical decisions are validated server-side rather than trusted from clients.

Network Entity Ownership

Every networked entity has a clearly defined owner, controlling who is allowed to replicate state changes for it across the network.
